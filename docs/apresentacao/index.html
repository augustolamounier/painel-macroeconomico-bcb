1 · Tema e problema

A inflação brasileira está sob controle?

  • Desde 1999 o Brasil tem uma meta de inflação, com intervalo de tolerância.
  • O Banco Central usa a taxa Selic para manter o IPCA dentro desse intervalo.
  • Inflação, juros e câmbio entram em decisões reais: reajustar contratos, tomar crédito, investir.
  • Problema: a meta tem sido cumprida? O que escapou, como os juros reagiram e quanto isso custou em poder de compra?

3 · Herança e polimorfismo

O painel não sabe como cada indicador é calculado

  • Herança: 3 hierarquias com classe base abstrata.
  • Polimorfismo: a mesma chamada, calcular(), executa regras diferentes.
  • Encapsulamento: atributos _privados e @property; dados devolve uma cópia.
  • Aberto/fechado: indicador novo = classe nova, sem mexer nas existentes.
class Indicador(ABC):
    @abstractmethod
    def calcular(self, analisador): ...

class IndicadorPoderDeCompra(Indicador):
    def calcular(self, analisador):
        acumulado = analisador.acumulado("ipca")
        return self._resultado(100 / (1 + acumulado / 100))

class PainelIndicadores:
    def calcular_todos(self, analisador):
        return [i.calcular(analisador)
                for i in self._indicadores]
3 · Princípios SOLID

SOLID aplicado

SO analisador não conhece Plotly nem Streamlit; os gráficos não fazem cálculo.
ONovas fontes, indicadores e gráficos entram como subclasses.
LQualquer FonteDados serve ao pipeline — inclusive a fonte falsa dos testes.
IClienteHTTP tem um único método: obter_json.
DDependências entram pelo construtor; as classes concretas são escolhidas só no app.py.

7 · Testes

77 testes, 95% de cobertura

  • Unitários: cada classe com dados sintéticos de resultado conhecido.
  • Sem internet: um cliente HTTP falso substitui a API (inversão de dependência).
  • Integração: o AppTest executa o dashboard inteiro e mexe nos filtros.
  • Dados conferidos: o IPCA em 12 meses publicado bate com o recalculado (diferença máxima de 0,009 p.p.).
  • Os testes encontraram um erro real de tipo de dado durante a integração.
8 · Conclusões

Conclusões e limitações

  • A meta é cumprida na maioria dos meses, mas com folga pequena.
  • A inflação é muito desigual entre os itens de consumo.
  • O juro real brasileiro é alto: 5,81% ao ano em média.
  • R$ 100 de 2000 valem R$ 20,64 hoje.
  • Análise descritiva: associação não é causalidade.
  • Juro real ex-post, não o esperado.
  • Grupos sem os pesos do IPCA.
  • Séries revisadas e com início em datas diferentes.
