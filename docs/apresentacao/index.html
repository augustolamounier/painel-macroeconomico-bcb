O problema

A inflação brasileira está sob controle?

01 · A REGRA

Desde 1999, o Conselho Monetário Nacional fixa uma meta para o IPCA, com um intervalo de tolerância.

02 · A FERRAMENTA

O Banco Central sobe ou desce a taxa Selic para manter a inflação dentro desse intervalo.

03 · A INVESTIGAÇÃO

O projeto verifica, com dados, como esse sistema se comportou de 2000 a 2026.

Conclusões

O que os dados mostram

56%dos meses dentro da meta, mas com pouca folga e desvios quase sempre para cima.
3,5×foi quanto Alimentação subiu a mais que Comunicação: a inflação é desigual.
5,81%ao ano é o juro real médio do período, um dos fatores que encarecem o crédito.
R$ 20,64é o que valem hoje R$ 100 de 2000: dinheiro parado perde valor rápido.

Limitações: análise descritiva (associação não é causalidade) · juro real calculado com a inflação passada · grupos do IPCA sem os pesos do índice · séries revisadas e com inícios diferentes.
